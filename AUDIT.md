# HunarHub Comprehensive Production Audit (AUDIT.md)

This document provides a complete production-style audit of **HunarHub: Digital Marketplace for Local Micro-Entrepreneurs** based on a trace of frontend components, API service layers, backend routes, controllers, database schema, and transactions.

## Detailed Audit Tracing by Role

### A. Customer Journey
1. **Discovery:** Customer visits `/`, views categories (Cobbler, Potter, Tailor, Artisan, Small Vendor). Real ratings and verified badges display only when verified in the database.
2. **Search & Filter:** Searches by city and price. Server-side queries filter active services and products.
3. **Cart & Checkout:** Items added to cart persist in `localStorage`. `CartPage` computes subtotal, GST, and grand total. Backend re-verifies prices and stock atomically with `FOR UPDATE`.
4. **Payment:** Order placed as `PENDING`. If gateway configured, Razorpay modal opens; otherwise clean Direct UPI/Cash flow is presented without fake signatures.
5. **Tracking & Review:** Order status moves from `PENDING` -> `CONFIRMED` -> `PROCESSING` -> `READY` -> `COMPLETED`. Only completed orders allow verified reviews.
6. **Quotes:** Customer submits custom requirement through `QuoteWizardModal`, receives artisan proposals, and accepts preferred quote.

### B. Entrepreneur Journey
1. **Registration & Onboarding:** Entrepreneur registers, sets trade profile with status `PENDING`. Profile is hidden from public search until Admin approval.
2. **Dashboard & Leads:** Entrepreneur logs in to `/entrepreneur`. Receives leads for their craft category, submits proposed price quotes.
3. **Fulfillment:** Receives service requests and product orders. Advances status (`PROCESSING` -> `READY` -> `COMPLETED`).
4. **Craft Management:** Manages skills, services, products, availability slots, and portfolio images.
5. **Ratings:** Views verified customer feedback and average rating dynamically calculated from DB.

### C. Admin Governance
1. **Security:** Route `/admin` is restricted to `user.role === 'ADMIN'`. Backend enforces `allowRoles('ADMIN')`.
2. **Verification:** Inspects pending artisan applications and approves/rejects with audit notes.
3. **Disputes:** Reviews customer complaints linked to orders or service requests and updates status with resolution notes.
4. **Analytics:** Views live metrics (monthly sales, average rating, customer order value) queried directly from database.
